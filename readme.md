# OSSU Programming Languages Course Progress

This repository documents my progress through the fourth course in the OSSU (Open Source Society University) roadmap: Programming Languages.

The course is divided into three parts, each focused on a different programming language and a different way of thinking about language design and computation:

- [Part A](https://www.coursera.org/learn/programming-languages): Standard ML (SML)
- [Part B](https://www.coursera.org/learn/programming-languages-part-b): Racket
- [Part C](https://www.coursera.org/learn/programming-languages-part-c): Ruby

## Overview

This repo contains lecture notes, sample programs, homework, and exercises completed during the course. It reflects a practical learning path in functional programming, language semantics, abstraction, and object-oriented design.

## Part A — Standard ML

Part A is the foundation of the course and focuses on Standard ML. It introduces core functional programming concepts such as:

- tuples, lists, and options
- algebraic data types and pattern matching
- higher-order functions and closures
- lexical scope and recursion
- type inference and polymorphism
- modules and signatures

### Completed work

I completed the core material for Modules 1 through 4:

- Module 1: introduction to SML basics, expressions, functions, tuples, and lists
- Module 2: records, datatypes, pattern matching, exceptions
- Module 3: higher-order functions, closures, currying, partial application, references, and callbacks
- Module 4: type inference, modules, signatures, and structured programming with ML modules

The repository also includes homework files and section summaries for each module, such as:

- `Module 1/Homework/hw1.sml`
- `Module 2/Homework/hw2.sml`
- `Module 3/Homework/hw3.sml`
- section summary PDFs for each module

This part shows the strongest progress in the repository and represents the main bulk of the course work.

## Learning Journey

This repository represents a multi-language exploration of programming language concepts across three paradigms:

1. Standard ML: strong static typing, functional purity, pattern matching, and type-driven design
2. Racket: dynamic, symbolic, and macro-heavy functional programming
3. Ruby: object-oriented and dynamic programming with blocks, closures, and inheritance mechanisms

This course is a key step in the OSSU roadmap, helping build a deeper understanding of how languages are structured, why different paradigms exist, and how programming concepts translate across languages.
